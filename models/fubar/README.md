# Browser FUBAR

An exact fixed-grid implementation of `CodonMolecularEvolution.jl`'s `DirichletFUBAR` workflow for WebAssembly and WebGPU. It shares the optimized MG94 pruning and global-fit kernels with the DifFUBAR package, then retains per-site alpha-beta posterior surfaces and marginals.

The reference default is a 20 × 20 grid (400 categories), 2,500 maximum EM iterations, concentration 0.5, and posterior threshold 0.95. Deterministic finite-Dirichlet EM is the inference default. An exact uncollapsed Gibbs option uses the same fused WASM rejection-draw strategy as DifFUBAR, with configurable burn-in and seed; its retained allocation counts feed the same visualization and CSV products. Parallel WASM is the browser default, and WebGPU is explicitly selectable.

The optional approximate-FEL companion follows `CodonMolecularEvolution.jl`'s `FIFEFUBAR` likelihood-ratio construction while hardening its interpolation and optimization. It fits the raw conditional log likelihoods—not posterior masses—in zero-based uniform grid-index coordinates, exactly reproduces every sampled node, and maps continuous optima back through the original FUBAR rate transform. Local bicubic derivatives reproduce quadratic likelihood bowls exactly; a curvature-envelope audit can tension the entire continuous surface toward its nodal-exact bilinear component if a cubic excursion is implausible. The global alternative uses multi-start coordinate refinement with exact stationary-point searches on every one-dimensional cubic interval. Approximate-FEL arrays, table, CSV, p-value controls, and SVG remain optional and separate from ordinary FUBAR output.
